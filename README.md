# 🚆 PriorityEngine – Smart Railway Operations Dashboard

PriorityEngine is an AI-powered railway operations management system designed for Indian Railways.  
It helps controllers **monitor trains in real time**, **manage schedules**, **handle disruptions**, and **optimize resources** from a single platform.

---

## 🏠 1. Dashboard (Main Control Center)

![Dashboard](https://github.com/user-attachments/assets/7fedd6c3-65af-4c95-9749-fae55527616f)

### Description
The Dashboard is the main command center. It shows the current status of the entire railway network at a glance.

### Features
- Indian Railways header with live IST time
- Navigation sidebar for all modules
- Interactive railway map with moving trains
- Color-coded trains:
  - Red – Express
  - Yellow – Freight
  - Blue – Local
- KPI cards:
  - Punctuality rate
  - Average delay
  - Throughput
  - Resource utilization
- AI recommendations with accept/override options
- Live alert ticker for disruptions

---

## 🗓️ 2. Scheduling & Train Precedence

![Scheduling](https://github.com/user-attachments/assets/773ba5c9-907d-443d-ae64-e08f82ad169f)

### Description
This screen is used to manage train schedules and decide which train goes first on shared tracks.

### Features
- Gantt chart timeline for all tracks
- Automatic conflict detection
- AI-based conflict resolution suggestions
- Search and filter trains by ID, type, or priority
- Drag-and-drop train precedence control
- AI optimization to reduce delays
- Export schedule as PDF or CSV

## 🔮 3. What-If Simulations

![Simulations](https://github.com/user-attachments/assets/38750839-1184-49a2-9eab-1028de0b0b2a)

### Description
This module allows testing different scenarios without affecting live operations.

### Features
- Add delays to trains
- Reroute trains
- Insert emergency trains
- Adjust weather impact
- Compare original vs simulated schedules
- AI impact analysis and optimization logs
- Save, export, and manage scenarios
